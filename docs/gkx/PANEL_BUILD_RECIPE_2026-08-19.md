## One-command summary

```bash
export WRDS_USER="your_wrds_username"
export PGPASSFILE="${PGPASSFILE:-$HOME/.pgpass}"
export STOCK_CHARACTERS_PROFILE=datashare
export STOCK_CHARACTERS_WRDS_DOWNLOAD_WORKERS=2   # WRDS I/O; keep 2–4
export STOCK_CHARACTERS_WORKERS=20                  # CPU compute (--workers)

cd /path/to/Stock_Characters

python Character_Panels/run_full_pipeline.py \
  --wrds-user "$WRDS_USER" \
  --profile datashare \
  --sample-start 1950-01-01 \
  --workers 20
```

## Pipeline stages (execution order)

Orchestrator: `Character_Panels/run_full_pipeline.py`

### 1. Bulk character build

`Character_Builders/build_all_implemented_characters.py`

- All implemented Green-style characters (annual, monthly, quarterly, daily, special).
- Inherits CCM/CRSP/sample flags from the resolved profile above.
- IBES `re` skipped (`--skip-ibes` default).

### 2. HXZ datashare targets

Built by `run_full_pipeline.build_hxz_characters()` **only if CSV missing**:

| Output CSV | Builder |
|------------|---------|
| `book_to_market.csv` | `Character_Builders/HXZ_BM_Generalized/build_book_to_market.py` |
| `operating_profitability.csv` | `Character_Builders/HXZ_OPE_Generalized/build_operating_profitability.py` |

SIC on `book_to_market.csv`: `comp.company.sic` (via Compustat merge in builder).

### 3. `bm_ia` (WRDS-free)

Built by `run_full_pipeline.build_datashare_bm_ia()` **only if `bm_ia.csv` missing**:

| Item | Detail |
|------|--------|
| Script | `Character_Builders/Datashare_BM_IA_Generalized/build_bm_ia.py` |
| Core logic | `Character_Builders/_shared/bm_ia_builder.py` |
| Input | `outputs/characteristics/individual/book_to_market.csv` |
| Formula | `bm_ia = book_to_market − mean(book_to_market)` over **(SIC2, signal_yyyymm)** |
| Industry | 2-digit SIC from 4-digit `comp.company.sic` on annual file |
| Statistic | Equal-weight mean (recomputed every month) |
| Timing | HXZ June expansion (`expand_annual_file_june`) |
| Output | `outputs/characteristics/individual/bm_ia.csv` (monthly-native) |

**Does not read `datashare.csv`.**

### 4. Excess returns

`Return_Builders/build_excess_returns.py` → `outputs/excess_returns.csv` (skipped if exists).

### 5. Signal panel merge

`Character_Panels/build_all_character_panel.py --profile datashare`

- Merges only the **95 datashare-mapped** predictors (`pipeline_config.datashare_output_columns()`).
- **No** Green joint universe screen (`bm` + `mom1m` + `mve` non-missing).
- **No** Green monthly winsorization.
- Output: `outputs/panels/all_character_signal_panel.csv`

Individual CSV directory: `outputs/characteristics/individual/`

## WRDS parallelism (important)

Two separate knobs — do not conflate them:

| Knob | Controls | Recommended |
|------|----------|-------------|
| `--workers` / `STOCK_CHARACTERS_WORKERS` | CPU compute pool (betas, rolling windows, etc.) | 8–20 on server |
| `STOCK_CHARACTERS_WRDS_DOWNLOAD_WORKERS` | Parallel WRDS `crsp.dsf` chunk downloads | **2–4** (avoid “too many connections”) |

If the build fails with `too many connections for role`, lower
`STOCK_CHARACTERS_WRDS_DOWNLOAD_WORKERS` and resume; keep `--workers` high for CPU steps.

## Clean rebuild checklist

These files are **skipped when they already exist** — stale copies will silently
pollute a “fresh” run:

```bash
rm -f outputs/characteristics/individual/book_to_market.csv
rm -f outputs/characteristics/individual/bm_ia.csv
rm -f outputs/excess_returns.csv
# Optional full wipe of individual chars:
# rm -f outputs/characteristics/individual/*.csv
```

- **Without `--resume`:** bulk Green builders overwrite existing CSVs.
- **With `--resume`:** bulk builders use `--skip-existing`.
- **HXZ + bm_ia + excess_returns:** always skip-if-exists regardless of `--resume`.

For a guaranteed clean datashare panel, delete the three files above before starting.
